# Кто я?

Игра для своей компании. У каждого «на лбу» стикер с персонажем: его видят все, кроме тебя. По очереди задаёте вопросы, на которые отвечают «да» или «нет», и угадываете, кто вы.

## Как играть

1. Один создаёт комнату и диктует код из шести цифр. Остальные входят по коду.
2. Хост выбирает, откуда стикеры: из готовой колоды или каждый пишет персонажа соседу.
3. В свой ход пишешь вопрос: «Я живой?», «Я из мультика?». Остальные отвечают «да», «нет» или «не знаю». Что выяснил, записывай в заметки.
4. Думаешь, что догадался: называй персонажа. Остальные голосуют, угадал ли ты. Партия идёт, пока не угадает первый или все (выбирается в лобби).

## Как устроено

Партию считает сервер `ktoya.wkiseven.me`: очередь ходов, ответы, голосование. Свой стикер сервер тебе не присылает, поэтому подсмотреть его в окне игры нельзя. Если связь пропала, игра сама вернёт тебя на то же место. Комнаты переживают перезапуск сервера: снимок пишется на диск.

## Разработка

```bash
npm install
npm run server      # сервер на :8787 (колода из server/characters.txt)
npm run web         # интерфейс в браузере: ?server=http://127.0.0.1:8787&profile=a
npm run dev         # то же в Electron
npm test            # правила, комната, патчноуты
npm run typecheck && npm run lint
```

`?profile=a`, `?profile=b` разводят профили по вкладкам, чтобы сыграть за нескольких в одном браузере.

```
src/engine      правила игры (чистые функции)
src/protocol    сообщения клиент ↔ сервер и то, что видит каждый игрок
src/client      сессия клиента
src/renderer    интерфейс (React)
src/main        оболочка Electron, автообновление (под лаунчером Sevensave выключено)
src-tauri/      компактная оболочка Tauri на Rust для Sevensave
server/         комнаты, колода, HTTP/WS, Dockerfile
tools/          иконка (npx electron tools/render-icon.cjs), патчноут релиза, арт каталога (tools/catalog)
```

Компактная сборка использует системный WebView на macOS 14+ и WebView2 на Windows. При первом запуске она копирует профиль, настройки и заметки из Electron. Для запуска нужен Rust и инструменты сборки целевой платформы.

```bash
npm run light:dev
npm run light:build -- --target aarch64-apple-darwin --bundles app -- --locked
bash tools/pack-light.sh aarch64-apple-darwin
```

Для Intel Mac укажи `x86_64-apple-darwin`. На Windows укажи `x86_64-pc-windows-msvc`, замени `--bundles app` на `--no-bundle` и запусти упаковку из Git Bash с доступным `7z`. Поле `light` из `tools/catalog/entry.json` нужно перенести в каталог Sevensave, чтобы лаунчер выбрал компактный zip. На остальных системах лаунчер берёт обычный zip из `assets`.

Релиз: поднять версию в `package.json`, дописать `src/renderer/src/changelog.ts`, запушить тег `vX.Y.Z`. Сборки для Windows и Mac уходят в релиз `sevensave/ktoya`, оттуда их берёт лаунчер Sevensave.
